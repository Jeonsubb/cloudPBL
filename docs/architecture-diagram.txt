  데이터 흐름 요약
══════════════════════════════════════════════════════════════════════════════════════════════════════

  [수집]  EventBridge 스케줄
              │
              ├── ECOS Collector ─── 한국은행 API ──→ DynamoDB (환율·금리)
              ├── KCCI Collector ─── KOBC API ─────→ DynamoDB (운임지수 13개 항로)
              └── News Collector ─── RSS 피드 ─────→ DynamoDB (뉴스 + 점수)

  [조회]  사용자 → 브라우저
              │
              └── API Gateway → Lambda (api-query / chat)
                                  │
                                  ├── DynamoDB 직접 조회 (시계열, 뉴스)
                                  ├── S3 회사 데이터 로드
                                  └── Bedrock Converse (추천 생성 / 챗봇 응답)

  [Agent] 챗봇/추천 → Bedrock Agent (단일)
              │
              ├── Action Group Lambda → DynamoDB 조회 (시장·뉴스·선적)
              ├── Knowledge Base (RAG) → S3 Vectors (해운 도메인 문서)
              └── 웹 검색 API → 실시간 외부 정보 (추후 연동)

  [Push]  EventBridge 07:00/07:30 KST
              │
              ├── News Digest Lambda → Bedrock → 텔레그램 (아침 브리핑)
              └── Reco Monitor Lambda → Bedrock → 텔레그램 (추천 변경 시)

  [초기화] 배포 직후 수동 invoke
              │
              └── Collector Lambda {"days":365} / {"weeks":250}
                  → DynamoDB에 과거 히스토리 bulk insert (차트 렌더링용)

  기술 스택
══════════════════════════════════════════════════════════════════════════════════════════════════════

  IaC:         AWS CDK (TypeScript/ESM)
  Lambda:      Node.js 22 (ESM)
  DB:          DynamoDB (PAY_PER_REQUEST)
  AI:          Amazon Bedrock - Claude Sonnet 4 (Converse API)
  보안:        Bedrock Guardrail (PII·투자조언·유해콘텐츠·Injection 차단)
  알림:        Telegram Bot API (Secrets Manager 보관)
  프론트:      Vanilla HTML/CSS/JS (SPA 없음, 정적 호스팅)
  스케줄:      EventBridge Scheduler (cron)
  스토리지:    S3 (회사 엑셀 + KB 문서) + DynamoDB (시계열·뉴스·추천)
