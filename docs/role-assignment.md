# 기능별 역할분담안

개발기간이 4~6일 정도라면 역할은 “기술 스택별”보다 “기능 완성 단위별”로 나누는 것이 좋습니다.

## 추천 역할 구조

| 담당 | 주요 책임 | 구체 작업물 |
| --- | --- | --- |
| A. 프론트엔드/UX 담당 | 사용자가 실제로 보는 화면 구현 | 로그인 화면, 대시보드, 선적 등록 폼, 파일 업로드 UI, 챗봇 UI, 리스크 카드 |
| B. 백엔드/API 담당 | 프론트와 AWS 서비스를 연결 | API Gateway/Lambda, 업로드 URL 발급, 선적 CRUD, 리스크 조회 API |
| C. 데이터/리스크 로직 담당 | 입력 데이터와 시장 데이터를 분석 가능하게 정리 | 엑셀/견적서 파싱, 데이터 모델 설계, 리스크 룰 엔진, 샘플 데이터 구축 |
| D. AI/AWS 인프라 담당 | Bedrock과 AWS 배포 구조 구현 | Bedrock 프롬프트, 챗봇/리포트 생성, SAM 템플릿, S3/Cognito/EventBridge 설정, 알림 |

## 기능별 상세 분배

### A. 프론트엔드/UX 담당

- React/Vite 프로젝트 세팅
- 선적 등록 화면
- 견적서/엑셀 업로드 화면
- 리스크 대시보드
- 챗봇 패널
- 리포트 보기/다운로드 버튼
- 발표용 데모 시나리오 화면 정리

### B. 백엔드/API 담당

- API Gateway 엔드포인트 설계
- Lambda 핸들러 작성
- S3 Presigned URL 발급
- 선적 목록/상세/등록/수정 API
- 리스크 결과 조회 API
- 프론트엔드와 API 연동 지원

### C. 데이터/리스크 로직 담당

- 회사 선적 데이터 필드 정의
- 견적서/엑셀 샘플 양식 제작
- 문서 파싱 결과 정규화
- KCCI, SCFI, 환율, 뉴스 샘플 데이터 정리
- 리스크 점수 규칙 작성
- 위험도 등급 산정

예시 규칙:

| 조건 | 점수 |
| --- | --- |
| 견적 유효기간이 3일 이하인데 부킹 미완료 | +30 |
| ETA와 납기일 차이가 5일 이하 | +25 |
| 선적 준비일이 CY Closing에 너무 가까움 | +20 |
| KCCI/SCFI 단기 상승 | +10 |
| 호르무즈/홍해/파업 뉴스가 관련 항로에 매칭 | +10 |

### D. AI/AWS 인프라 담당

- Amazon Bedrock 호출 코드 작성
- 리스크 설명 프롬프트 작성
- 챗봇 질의응답 프롬프트 작성
- EventBridge 수집 스케줄 구성
- S3, Cognito, Lambda, API Gateway 설정
- 텔레그램 알림 연동
- CloudWatch 로그 확인

## 발표 기준 핵심 담당자

- 데모 진행: 프론트엔드 담당
- 문제정의/사용자 설명: 데이터/리스크 담당
- AWS 구조 설명: AI/AWS 인프라 담당
- 구현 흐름/API 설명: 백엔드 담당
