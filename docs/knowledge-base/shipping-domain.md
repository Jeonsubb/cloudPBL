# PortPulse 해운 도메인 지식

## 1. KCCI 컨테이너선 운임지수

### 개요
KCCI(Korea Container Cargo Index)는 한국해양진흥공사(KOBC)가 매주 월요일 14시에 발표하는 부산 출발 컨테이너선 운임지수입니다. 2022년 11월 7일에 공표를 시작했으며, 기준시점(2019년 1월 첫째 주) 대비 운임 수준을 지수화합니다.

### 구성
- **종합지수(KCCI)**: 13개 세부항로의 가중평균
- 세부항로 (총 13개):
  - 북미서안(KUWI) 15%, 북미동안(KUEI) 10%
  - 북유럽(KNEI) 10%, 지중해(KMDI) 5%
  - 중동(KMEI) 5%, 오세아니아(KAUI) 5%
  - 중남미동안(KLEI) 5%, 중남미서안(KLWI) 5%
  - 남아프리카(KSAI) 2.5%, 서아프리카(KWAI) 2.5%
  - 중국(KCI) 15%, 일본(KJI) 10%, 동남아(KSEI) 10%

### 해석 기준
- **1000pt 이상**: 기준시점(2019) 대비 운임 수준 유지/상승
- **1000pt 미만**: 기준시점 대비 하락
- **주간 변동 ±3% 이상**: 급등락으로 판단, 부킹 의사결정에 주의 필요
- **52주 백분위 80% 이상**: 최근 1년 대비 고점 구간 — 조기 부킹 고려
- **52주 백분위 20% 이하**: 최근 1년 대비 저점 구간 — 관망 여지 있음

### 활용
- 현재 운임 수준이 과거 대비 어디에 위치하는지 정량적으로 판단
- 항로별 수급 상황 비교 (예: 미주서안은 상승 중이나 동남아는 보합)
- 부킹 타이밍 결정의 핵심 근거


## 2. SCFI와 KCCI의 차이

| 항목 | KCCI | SCFI |
|------|------|------|
| 발행기관 | 한국해양진흥공사(KOBC) | 상하이해운거래소(SSE) |
| 기준항 | 부산 출발 | 상하이 출발 |
| 발표주기 | 매주 월요일 | 매주 금요일 |
| 적용성 | 한국 수출기업에 직접 적용 | 글로벌 벤치마크, 간접 참고 |

한국 수출기업에게는 KCCI가 더 직접적인 운임 지표입니다.


## 3. 운임 구성 요소

### 기본운임 (Base Freight / Ocean Freight)
- 컨테이너 1개(20ft/40ft)당 해상 운송 기본 비용
- 단위: USD/TEU 또는 USD/FEU (20피트/40피트 기준)

### 할증료 (Surcharges)
- **BAF (Bunker Adjustment Factor)**: 유류비 변동 할증
- **CAF (Currency Adjustment Factor)**: 환율 변동 할증
- **THC (Terminal Handling Charge)**: 터미널 하역비
- **PSS (Peak Season Surcharge)**: 성수기 할증 (7~9월, 11~12월 일반적)
- **GRI (General Rate Increase)**: 선사 일반 운임 인상 (보통 1~2개월 전 공지)
- **EBS (Emergency Bunker Surcharge)**: 긴급 유류 할증

### 부대비용
- 서류비(Documentation Fee)
- 컨테이너 불균형료(Container Imbalance Surcharge)
- 전쟁 위험 할증료(War Risk Surcharge) — 홍해 사태 시 적용

### 견적 비교 시 주의점
- 같은 항로라도 "포함 항목"이 포워더마다 다를 수 있음
- 비교 시 반드시 같은 scope(항구~항구, 문전~문전 등)끼리 비교해야 함


## 4. Incoterms (무역 조건)

### 주요 조건과 물류비 영향

| 조건 | 운임 부담 | 리스크 전환점 |
|------|-----------|---------------|
| FOB (Free On Board) | 수입자가 해상운임 부담 | 선적항 본선 적재 시 |
| CIF (Cost, Insurance, Freight) | 수출자가 해상운임+보험 부담 | 도착항 |
| CFR (Cost and Freight) | 수출자가 해상운임 부담 | 도착항 |
| DDP (Delivered Duty Paid) | 수출자가 전체 부담 | 수입자 지정 장소 |

### 부킹 의사결정과의 관계
- **FOB 조건**: 수출자가 부킹을 통제하지 않으므로, 운임 상승이 직접적 비용 영향 없음
- **CIF/CFR 조건**: 수출자가 부킹을 통제하며, 운임 상승이 직접 비용 증가
- **DDP 조건**: 수출자 부담이 가장 크므로, 운임·환율·관세 모두 민감

수출자가 운임 부담 조건(CIF/CFR/DDP)일 때만 "부킹 타이밍 최적화"가 의미 있습니다.


## 5. 부킹 타이밍 의사결정 프레임워크

### 즉시 부킹 권고 (BOOK_NOW) 조건
- KCCI 52주 백분위 40% 이하 (저점 구간에서의 기회)
- 운임이 3주 연속 상승 중
- 성수기(7~9월) 진입 2~4주 전
- GRI 발효 2주 이내
- 납기까지 남은 항차 수가 2편 이하

### 관망 권고 (CONSIDER_WAIT) 조건
- KCCI 52주 백분위 80% 이상 (고점에서 하락 가능성)
- 운임이 2주 연속 하락 중
- 비수기(1~3월) 진입 예상
- 납기 여유가 4주 이상 + 남은 항차 3편 이상

### 핵심 원칙
1. **납기 우선**: 납기를 못 맞추면 운임 절감은 의미 없음. 납기 버퍼 5일 미만이면 무조건 가장 빠른 항차 부킹.
2. **예산 대비 판단**: 현재 운임이 예산 대비 10% 이상 초과면 경보 발생.
3. **트렌드 + 레벨**: 단순히 "지금 높다/낮다"가 아니라 "오르는 중인지/내리는 중인지"를 함께 판단.


## 6. 성수기/비수기 패턴

### 해운 운임 계절성 (부산 출발 기준)
- **1~2월**: 설 연휴 전 물량 집중 후 비수기 진입
- **3~5월**: 비수기 — 운임 하락 또는 보합 경향
- **6~9월**: 성수기 — 연말 소비재 수요 대비 선적 집중. GRI 빈발.
- **10월**: 국경절(중국) 이후 일시 소강
- **11~12월**: 블랙프라이데이·크리스마스 수요 + 설 전 조기 선적

### 의미
- 성수기 진입 전에 미리 부킹 확보하면 할증·선복 부족 리스크 완화
- 비수기에는 관망 후 저점 부킹 가능성 높음


## 7. 환율과 물류비 관계

### 원/달러 환율의 영향
- 대부분의 해상운임은 USD로 결제
- 원/달러 상승(원화 약세) → 원화 기준 물류비 증가
- CIF 조건 수출자: 환율 상승 시 실질 마진 감소

### 실무 판단
- 환율이 2주 내 2% 이상 급등하면, 비용 산정 시 환율 리스크 별도 반영 필요
- 장기 계약(3개월 이상 선적)에서는 환헤지 고려 필요

### 기준금리
- 기준금리 인상 → 원화 강세 요인 (물류비 원화 환산 시 유리)
- 기준금리 인하 → 원화 약세 요인 (물류비 부담 증가 가능)


## 8. 주요 리스크 이벤트

### 홍해/수에즈 운하
- 후티 반군 공격으로 수에즈 운하 우회 시: 유럽 항로 14~20일 추가, 운임 50~100% 급등 사례
- 우회 장기화 시 선복 부족 → 타 항로(미주/동남아)까지 파급

### 항만 파업
- 미국 서안/동안 항만 파업: 체선(vessel waiting) → 스케줄 지연 + 운임 급등
- 대비책: 조기 부킹 + 대안 항로(예: 미주서안 대신 미주동안 경유)

### 선사 동맹 재편
- 2M, THE Alliance, Ocean Alliance 등 해체/재편 시 항로별 선복 변동
- 재편기에는 기존 계약 운임 유지 어려울 수 있음

### 유류가격 급등
- BAF(유류할증) 직접 연동 — 유가 급등 시 할증료 인상 공지 선행


## 9. 포워더 선택 가이드

### 고려 요소
1. **해당 항로 취급 실적**: 미주 전문, 유럽 전문 등 강점 상이
2. **선사 계약 물량**: 물량이 큰 포워더가 운임 협상력 높음
3. **서비스 범위**: Door-to-Door vs Port-to-Port
4. **결제 조건**: 선불(Prepaid) vs 후불(Collect)
5. **클레임 대응력**: 화물 사고 시 처리 속도

### 견적 비교 시 체크리스트
- ✅ Ocean Freight (기본 해상운임)
- ✅ THC (터미널 비용) 양항 포함 여부
- ✅ Documentation Fee
- ✅ BAF/CAF 포함 또는 별도 청구 여부
- ✅ 유효기간 (보통 7~14일)
- ✅ Free Time (컨테이너 무료 사용 일수)
- ✅ 환적 횟수 및 총 소요일수


## 10. 용어 정리

| 용어 | 설명 |
|------|------|
| TEU | Twenty-foot Equivalent Unit (20피트 컨테이너 1개) |
| FEU | Forty-foot Equivalent Unit (40피트 컨테이너 1개) |
| ETD | Estimated Time of Departure (출항 예정일) |
| ETA | Estimated Time of Arrival (도착 예정일) |
| CY | Container Yard (컨테이너 야적장) |
| FCL | Full Container Load (만재 컨테이너) |
| LCL | Less than Container Load (혼재 화물) |
| B/L | Bill of Lading (선하증권) |
| SI | Shipping Instruction (선적 지시서) |
| VGM | Verified Gross Mass (검증 총중량) |
| CFS | Container Freight Station (혼재 작업장) |
| Demurrage | 컨테이너 반납 지연 시 발생하는 비용 |
| Detention | 컨테이너 장치장 외부 보관 시 발생하는 비용 |
| Free Time | 무료 컨테이너 사용 기간 |
| Roll-over | 선적 예정이던 화물이 다음 항차로 이월되는 것 |
| Booking Confirmation | 선사로부터 받는 선적 예약 확인서 |
