# 부킹 타이밍 의사결정 가이드

## 판단 흐름 (Decision Flow)

```
1. 납기 확인
   └─ 납기 버퍼 < 5일? → 무조건 즉시 부킹 (납기 우선)
   └─ 아니면 → 2번으로

2. 시장 수준 확인
   └─ KCCI 52주 백분위 확인
   └─ 주간 추세 확인 (상승/하락/보합)
   └─ 성수기 진입 여부 확인

3. 예산 대비 확인
   └─ 현재 시장가 vs 예산 → 초과율 계산
   └─ 과거 자사 실거래가 대비 수준 확인

4. 종합 판단
   └─ BOOK_NOW / BOOK_SOON / CONSIDER_WAIT / DEADLINE_RISK
```


## 각 판단(Stance)의 정의

### BOOK_NOW (지금 예약)
**의미**: 지금 부킹하지 않으면 비용이 더 올라가거나, 납기를 못 맞출 리스크가 높음.

**트리거 조건 (하나 이상 충족)**:
- 납기까지 남은 항차 ≤ 2편
- KCCI 3주 연속 상승 + 52주 백분위 50% 초과
- GRI 발효까지 2주 이내
- 성수기(7~9월) 진입 3주 이내 + 운임 상승 중

**실무 행동**:
- 가장 빠른 직항 항차 부킹 확정
- 포워더에 즉일 Booking Confirmation 요청
- SI(선적지시서) 준비 시작


### BOOK_SOON (곧 예약)
**의미**: 1~2주 내 부킹이 유리하나, 며칠 여유는 있음.

**트리거 조건**:
- 납기까지 남은 항차 3~4편
- KCCI 상승 추세이나 급등은 아님
- 예산 대비 현재 운임 +5~10% 구간

**실무 행동**:
- 2~3개 포워더에 견적 요청 (3일 내 회수)
- 최적 항차 1순위+대안 2순위 선정
- 1주 내 부킹 확정 목표


### CONSIDER_WAIT (관망)
**의미**: 시장이 하락 추세이거나, 현재가 고점이라 기다리면 더 나은 조건 가능.

**트리거 조건**:
- KCCI 52주 백분위 > 75% + 하락 추세
- 비수기(1~3월) 진입 예상
- 납기 여유 4주 이상 + 남은 항차 4편 이상
- 성수기 종료(10월~) 후 운임 하락 패턴

**실무 행동**:
- 현재 견적 유효기간 확인 (만료 전 재견적 필요)
- 1주 후 재평가 스케줄 설정
- 시장 모니터링 강화 (뉴스/KCCI 주간 확인)

**주의**: "관망"은 "무기한 대기"가 아님. 반드시 재검토일을 정할 것.


### DEADLINE_RISK (납기 위험)
**의미**: 납기 충족 가능한 항차가 부족하거나, 이미 위험 구간 진입.

**트리거 조건**:
- 납기까지 남은 항차 ≤ 1편
- 모든 항차의 ETA가 납기 버퍼를 못 맞춤
- Roll-over 리스크 고려 시 안전마진 없음

**실무 행동**:
- 즉시 가장 빠른 항차 부킹 (운임 무관)
- 환적 포함 대안 경로 동시 확보
- 수입자에게 납기 지연 가능성 사전 고지
- 필요시 항공 전환(Air Freight) 부분 검토


## 예산 초과 시 행동 가이드

| 초과율 | 권장 행동 |
|--------|-----------|
| 0~5% | 수용 가능 범위. 부킹 진행. |
| 5~15% | 재견적 요청 + 대안 포워더 추가 비교 |
| 15~30% | 경영진 보고 + 선적 시점 조정 검토 |
| 30%+ | 특별 승인 필요 + 대안 운송 모드(항공/철도) 검토 |


## 재검토 트리거 (Watch Triggers)

다음 중 하나라도 발생하면 현재 판단을 재평가해야 합니다:

1. **KCCI 주간 변동 ±5% 이상** — 시장 방향 급변
2. **GRI/PSS 공지** — 2~4주 내 운임 인상 확정
3. **항만 파업/홍해 사태 악화** — 선복 부족 + 운임 급등
4. **환율 2% 이상 급변** — 원화 환산 비용 변동
5. **견적 유효기간 만료 2일 전** — 현재 견적 유효 확인
6. **경쟁 포워더 새 견적 입수** — 더 나은 조건 비교


## 판단 신뢰도(Confidence) 기준

| 등급 | 조건 |
|------|------|
| HIGH | KCCI 데이터 최신(7일 이내) + 견적 유효기간 내 + 환율 안정 |
| MEDIUM | KCCI 1~2주 지연 또는 견적 유효기간 임박 |
| LOW | 시장 데이터 부재 또는 견적 없음 또는 돌발 이벤트 발생 |
